# buffingchi.com

Navigation hub for buffingchi.com — links to Games, BookshelfAI, RulersAI, and Reports.

## Stack

React + Vite | Tailwind CSS 4 | i18next (13 locales)

## Commands

- `npm run dev` — dev server
- `npm run build` — production build
- `npm run test:run` — tests (CI)
- `npm run test:coverage` — tests with coverage
- `npm run lint` — lint
- `npm run i18n:check` — check for untranslated strings
- `npm run i18n:translate` — translate with OpenAI
